## Start here

1. Read the [module outline](content/00_module_outline.md) (10 minutes).
2. Read the chapters in order: [Part 1](content/01_algorithms/README.md), [Part 2](content/02_data_structures/README.md), [Part 3](content/03_connectionist_ai/README.md).
3. In each chapter: predict first, do the activity on paper or on the platform, then read the answers.
4. Test yourself with the [Test Bank](test_bank/).

**You need:** a web browser or any Markdown viewer. Python examples are optional.
